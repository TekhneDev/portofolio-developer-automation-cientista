## Contexto

O time de dados descobria problemas pelos usuários finais. Não havia visão central de quais tabelas estavam atrasadas, incompletas ou com valores fora do esperado.

## Decisões técnicas

- **Testes no dbt** (unicidade, nulos, faixas, atualização) rodando a cada carga.
- **Painel em React + D3** com mapa de saúde por domínio e histórico de cada teste.
- **Responsável por tabela**: o alerta vai direto para quem pode corrigir.

## O que aprendi

Um painel só funciona se alguém olha. Os alertas certos, para a pessoa certa, foram mais importantes que os gráficos.
